Perguntas Frequentes

O consórcio faz sentido para quem já tem dinheiro investido?

Sim. Uma das estratégias é usar o consórcio para alavancar patrimônio, mantendo o seu capital investido rendendo. Você usa uma parcela do rendimento para pagar a parcela do consórcio, sem descapitalizar.

Posso usar para comprar equipamentos para a clínica?

Sim. Existem modalidades de consórcio para bens móveis que permitem a compra de equipamentos, máquinas e veículos de forma planejada e sem juros.

A ALTAMAR cobra pela consultoria?

Não. Nosso serviço de consultoria e acompanhamento é gratuito para o cliente. Somos remunerados pela Ademicon.
